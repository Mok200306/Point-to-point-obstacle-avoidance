## 轨迹图和指标

每个正式运行目录至少包含：

- `trajectory_comparison.png`：左侧 Gazebo 真值俯视图，右侧 RViz/costmap 风格图；
- `trajectory.png`；
- 在线规划轨迹和 Gazebo 真值轨迹 CSV；
- `metrics.yaml`、`多目标指标.yaml`；
- `实验参数.yaml`、`导航参数.yaml`、`碰撞监视参数.yaml`；
- `世界文件.sdf` 和 Gazebo contacts 证据。

动态场景还必须保存 `动态障碍轨迹.csv`、`gazebo_contacts_raw.log.gz`、
`gazebo_contacts_summary.yaml` 和运行时有效参数快照；这些证据不能用静态世界
文件或预录路线替代。

查看场景 02 v13 图像：

```bash
find results/05_跨场景验证/场景02/01_正式验收/场景02_四点闭环_目标线轻偏好v13_2026-08-23 \
  -name trajectory_comparison.png -print | sort
```

## 新实验保存规则

当前新实验默认基础 profile 为
`adaptive_goal_line_050_recovery_v13_line_tiebreaker`。如果使用
`adaptive_goal_line_045`，必须在实验参数和阶段文档中明确标注为对照或历史复现；不
得把旧场景03的 045 结果改写成 v13 结果。

新实验必须使用新的 label，不能复用正式的 `run_01`、`run_02`、`run_03`：

```bash
--label 05_跨场景验证/场景02/03_新实验/复现_v13_$(date +%Y%m%d_%H%M%S)
```

只有同时满足以下条件才计入正式统计：全部目标段 `status=4`、
`gazebo_non_ground_contact: false`、contacts 对为 `(none)`，且参数/世界/commit 可追溯。
`status=6` 的安全停止即使无碰撞，也只能作为失败或历史参考。
