# 中文版说明

本版本不是简单把文件名翻译成中文，而是以“别人拿过去能直接用”为目标处理：

1. `README`、完整手册、配置说明、集成说明、示例代码全部中文化。
2. `WaterChassis` 公共方法增加中文 docstring，VSCode/Pylance 悬停即可看到中文说明。
3. 动作过程控制台反馈汉化，例如“转向中 / 行驶中 / 已走 / 剩余 / 位姿 / 线速度 / 角速度”。
4. 常见 SDK/Gateway 错误提示汉化。
5. 保留英文正式方法名和机器字段名，避免破坏代码兼容性。
6. 额外提供中文类名 `Water底盘` 和中文方法别名，方便初学者，但正式多人项目仍推荐英文主接口。
7. 所有底层 `.py` 源码均完整保留在 `water_chassis_sdk/` 中，没有做二进制封装或删减。

因此推荐：

```python
from water_chassis_sdk import WaterChassis
```

而不是把正式项目完全写成中文函数名。
