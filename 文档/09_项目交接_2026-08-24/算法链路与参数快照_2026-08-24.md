# 算法链路与参数快照

## 1. 在线实时规划是否成立

成立，但结论限定在已验证的静态仿真场景。启动时 `online:=true`、
`localization:=false`，RTAB-Map持续接收RGB-D图像和深度，发布地图和 `map->odom`；
Nav2同时用全局地图和局部RGB-D障碍层规划。每一个目标段在当前机器人位置和目标
之间重新求解，不回放历史轨迹。

机器人经过的位置会被 RTAB-Map 的图优化/地图记忆保留。后续再次经过时，地图通常
比第一次更完整，但在线地图仍受回环、遮挡、深度质量和 TF 影响；“记住”不等于未来
路径固定，也不等于未知区域已经提前可见。

## 2. 规划器和控制器

| 模块 | 作用 |
| --- | --- |
| GoalLineSmacPlanner | 基于 SmacPlanner2D，在可行栅格中对当前起点到目标直线增加软偏好 |
| global costmap | 合并 RTAB-Map 静态/地图层和实时障碍层，提供全局可行性 |
| RPP | 跟踪全局路径，根据曲率、代价和前视碰撞预测调节速度 |
| collision_monitor | 使用降采样RGB-D点云建立前方减速区/停止区，输出安全速度 |
| recovery behavior tree | 清理 costmap、旋转、等待、短距离后退后重规划 |

黑色目标直线是记录和代价偏好的参考，不是额外发送给底盘的轨迹；彩色线是实际
规划/控制后的运动轨迹。

## 3. 通用基线 profile

`adaptive_goal_line_045` 主要值：

| 参数 | 值 |
| --- | ---: |
| global/local inflation radius | 0.45 m |
| 目标线软偏好 | 开启，按当前 start/goal 动态计算 |
| `cost_travel_multiplier` | 6.0 |
| RPP 速度（基线） | 约 0.28 m/s |
| footprint | 约 0.60 × 0.48 m，padding 0.03 m |
| goal XY/yaw tolerance | 0.12 m / 0.15 rad |
| reversing | 常规控制关闭，恢复行为可执行短距离 BackUp |

## 4. 场景 02 v13 profile

`adaptive_goal_line_050_recovery_v13_line_tiebreaker` 主要值：

| 参数 | 值 |
| --- | ---: |
| global/local inflation radius | 0.50 m |
| `line_bias_max_cost` | 18.0 |
| `line_bias_distance_scale` | 2.8 m |
| `line_bias_exponent` | 2.0 |
| `cost_travel_multiplier` | 6.0 |
| `goal_progress_bias` | 关闭 |
| `unknown_bias` | 关闭 |
| `side_bias` | 关闭 |
| 周期重规划 | 约 6 s |
| RPP desired velocity | 0.28 m/s |
| RPP lookahead | 0.52--1.05 m，时间前视约 1.5 s |
| `allow_reversing` | false |

v13 的目标是避免旧 v5 在 N→X 出现南侧长回环，同时保留障碍硬约束和安全监视器。
它不是场景坐标走廊，也不包含 `(6,-6)` 等途经点。
