## 归档规则

- 当前冻结 profile adaptive_goal_line_045 只作为对照，不直接覆盖修改。
- 新场景使用新的世界文件、实验标签和结果目录；保留每个场景至少三次独立运行。
- 每次实验保存轨迹图、CSV、metrics、参数快照、世界文件和 contacts 证据。
- 只有通过成功率、末端误差和物理接触检查后，才把结果写入阶段结论。
- 算法代码、参数和实验文档的变化分别通过 Git 提交记录；本目录只记录阶段结论和复现方法。

当前冻结基线的详细内容见
