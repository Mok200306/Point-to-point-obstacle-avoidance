## 2. 规划和控制参数

### GoalLineSmacPlanner

| 参数 | v13 值 | 作用 |
| --- | ---: | --- |
| 插件 | `rtabmap_tb3_nav/GoalLineSmacPlanner` | SmacPlanner2D 的实时目标线软偏好扩展 |
| `cost_travel_multiplier` | `6.0` | 累计路径代价权重 |
| `line_bias_enabled` | `true` | 只对已知非致命自由栅格增加软代价 |
| `line_bias_max_cost` | `18.0` | 偏离当前起终点线的最大附加代价 |
| `line_bias_distance_scale` | `2.8 m` | 软代价距离尺度 |
| `line_bias_exponent` | `2.0` | 二次距离惩罚 |
| `line_bias_apply_to_unknown` | `false` | 不给未知空间叠加目标线偏好 |
| `goal_progress_bias_enabled` | `false` | 不使用 v12 的未知空间目标进度惩罚 |
| `unknown_bias_enabled` | `false` | 不额外惩罚未知栅格 |
| `side_bias_enabled` | `false` | 不使用场景坐标侧向先验 |
| `allow_unknown` | `true` | 保留在线建图时探索未知区域的基础能力 |

目标线每次由当前 `start` 和当前 `goal` 计算；在 N→X、X→Y 等新目标到达后，线会随目标
改变。它不是记录好的路径，也不会把 `(6,-6)` 或任何世界坐标写入规划器。

## 3. 复现命令

### 构建工作区

```bash
cd /home/w417/RTAB-Map
sg docker -c './scripts/stop.sh'
sg docker -c './scripts/start.sh'
sg docker -c 'docker compose exec -T ros2 bash -lc "source /opt/ros/humble/setup.bash && cd /workspaces/rtabmap_tb3_nav && colcon build --symlink-install"'
```

如果只是使用已经编译好的 v13，不需要每次重新构建；修改代码或 launch/profile 后再构建。

### 启动 Gazebo + RViz2

在终端1保持前台运行：

```bash
cd /home/w417/RTAB-Map
sg docker -c './scripts/launch_demo.sh \
  gazebo_gui:=true rviz:=true rtabmap_viz:=false \
  reset_db:=true online:=true localization:=false \
  world_file:=/workspaces/rtabmap_tb3_nav/src/rtabmap_tb3_nav/worlds/indoor_obstacle_course_cross_scene_02.world \
  navigation_profile:=adaptive_goal_line_050_recovery_v13_line_tiebreaker \
  x_pose:=-8.5 y_pose:=0.0'
```

### 运行一次新的四点闭环

在终端2使用全新的 label，不能覆盖正式 `run_01`、`run_02`、`run_03`：

```bash
cd /home/w417/RTAB-Map
sg docker -c './scripts/multi_waypoint_regression.sh \
  --start-name M --start-x -8.5 --start-y 0.0 \
  --goal N:8.5:0.0:0.0 \
  --goal X:-3.0:-4.0:0.0 \
  --goal Y:5.0:5.0:0.0 \
  --goal M:-8.5:0.0:0.0 \
  --profile adaptive_goal_line_050_recovery_v13_line_tiebreaker \
  --world-file src/rtabmap_tb3_nav/worlds/indoor_obstacle_course_cross_scene_02.world \
  --label 05_跨场景验证/场景02/03_新实验/复现_四点闭环v13_$(date +%Y%m%d_%H%M%S) \
  --contact-timeout 1200 --settle-seconds 5'
```

脚本会保存 `metrics.yaml`、`多目标指标.yaml`、双视角 `trajectory_comparison.png`、
`trajectory.png`、规划/真值 CSV、四段 CSV、世界快照、导航参数和碰撞监视参数。确认结果：

```bash
rg -n 'overall_succeeded|nav2_status|gazebo_non_ground_contact|gazebo_contact_pairs' \
  results/05_跨场景验证/场景02/03_新实验/复现_四点闭环v13_*/metrics.yaml
```
