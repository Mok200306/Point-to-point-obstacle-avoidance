## 3. 自动完成和需要手动选择的部分

### 系统自动完成

- demo.launch.py 读取 world_file 并启动对应 SDF；
- multi_waypoint_regression.sh 解析 SDF 中的 world name；
- contacts 主题自动生成：
  /gazebo/<world_name>/physics/contacts；
- 绘图脚本从传入的 SDF 自动读取墙体、障碍物和 marker；
- Nav2 仍然只接收 RGB-D、RTAB-Map 地图和实时 costmap；
- Gazebo 的 SDF 不会被交给规划器作为先验地图。

### 你需要在命令中选择

只需要在启动命令中指定 world_file，不需要手动修改源码或 YAML：

~~~bash
world_file:=indoor_obstacle_course_cross_scene_01.world
~~~

如果以后新增 cross_scene_02.world，也只需要替换这个文件名，并为实验使用新的
结果标签。新增世界文件后要重新构建工作区，使其进入 ROS 2 安装空间。

## 4. 新场景启动方式

先构建当前工作区：

~~~bash
cd /home/w417/RTAB-Map
sg docker -c './scripts/stop.sh'
sg docker -c './scripts/start.sh'
sg docker -c 'docker compose exec -T ros2 bash -lc "source /opt/ros/humble/setup.bash && cd /workspaces/rtabmap_tb3_nav && colcon build --symlink-install"'
~~~

启动场景 01 的 Gazebo、RViz2 和在线 RGB-D 建图：

~~~bash
sg docker -c './scripts/launch_demo.sh \
  world:=obstacle_course_large \
  world_file:=indoor_obstacle_course_cross_scene_01.world \
  x_pose:=-8.5 y_pose:=0.0 \
  gazebo_gui:=true rviz:=true rtabmap_viz:=false \
  online:=true localization:=false reset_db:=true \
  navigation_profile:=adaptive_goal_line_045'
~~~

这里保留 world:=obstacle_course_large 是为了继续复用自定义世界的 Gazebo、机器
人和传感器启动分支；真正加载的世界由 world_file 决定。

## 6. 正式回归命令模板

回归脚本会自动生成 contacts 主题，不需要手动填写 --contacts-topic：

~~~bash
sg docker -c './scripts/multi_waypoint_regression.sh \
  --goal P1:8.0:-4.5:0.0 \
  --goal P2:8.0:4.5:1.5708 \
  --goal P3:-7.5:4.5:3.1415926 \
  --goal P4:-7.5:-4.5:-1.5708 \
  --goal P0:-8.5:0.0:3.1415926 \
  --start-name P0 --start-x -8.5 --start-y 0.0 \
  --world-file src/rtabmap_tb3_nav/worlds/indoor_obstacle_course_cross_scene_01.world \
  --label "跨场景_场景01_五点闭环_run_01" \
  --profile adaptive_goal_line_045 \
  --settle-seconds 5'
~~~

P1--P4 是本阶段的建议初始点位，用于形成与旧 M-A-B-C-D-M 不同的路线。第一次
烟雾测试前应在 Gazebo 俯视图确认机器人出生点和目标周围没有被箱体占据；如果需要
调整点位，只改命令中的 goal，不改世界文件和算法参数。

三次实验必须：

- 使用 run_01、run_02、run_03 三个不同 label；
- 每次重新启动 Gazebo 和 RTAB-Map；
- 保持 adaptive_goal_line_045 和 reset_db=true；
- 保存每次的 trajectory_comparison.png、CSV、metrics、参数快照、世界文件和
  contacts；
- 不把一次成功的烟雾测试写成三次正式验收。
