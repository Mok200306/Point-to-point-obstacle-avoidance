## 1. 最终结论

当前项目已经在本大室内仿真场景中完成“RGB-D 在线建图 + Nav2 实时全局/局部规划 + 点到点避障 + 多目标闭环 + 物理接触检查”的功能验证。

三种五点闭环顺序共完成 9 次独立 run：

- 完整 run 成功：`9/9 = 100%`；
- 目标段成功：`45/45 = 100%`；
- 过滤地面后的非地面 Gazebo contacts：`0/9`；
- 每次均保存 Gazebo 真值与 RViz 风格地图左右合成图、CSV、metrics 和参数快照。

这个结论只适用于当前世界、模型和仿真传感器。它是当前场景的可复现基线，不是任意未知房间、任意窄通道或真实 D435i 上的工程级保证。

统一统计见 [点位顺序跨实验统一分析_2026-08-22.md](../06_五点闭环与顺序验证_2026-08-22/点位顺序跨实验统一分析_2026-08-22.md)。

## 3. 算法链路

```text
Gazebo RGB-D
  -> RTAB-Map online SLAM -> /map, map->odom
  -> map_padder -> fixed /nav_map
  -> Nav2 global costmap + live RGB-D obstacle layer
  -> GoalLineSmacPlanner / SmacPlanner2D
  -> RPP local controller
  -> /cmd_vel -> collision_monitor -> /cmd_vel_safe
  -> Gazebo Waffle
```

`adaptive_goal_line_045` 的关键定义：

- 每个目标创建新的 `NavigateToPose` action；
- planner 每次从当前 start、当前 goal 和当前 live costmap 搜索；
- `line_bias=true` 只对本次起终点直线施加软偏好；
- `side_bias=false`、目标 schedule=false，关闭旧 large 场景固定世界坐标走廊；
- 不订阅真实或仿真 `/scan`，障碍来自 RGB-D 深度点云；
- `inflation_radius=0.45 m`、矩形 footprint `0.60 x 0.48 m`、padding `0.03 m`；
- RPP 目标速度 `0.28 m/s`，lookahead 默认 `0.80 m`，范围 `0.62--1.20 m`；
- `collision_monitor` 作为最终速度安全层，非规划器的替代品。

详细参数和从零复现命令见 [自适应目标线算法复现手册_2026-08-22.md](../05_自适应目标线_2026-08-21至22/自适应目标线算法复现手册_2026-08-22.md)。

## 5. 参数冻结与后续边界

本轮冻结的不是“对所有环境都最优”的参数，而是当前场景经过 9 次独立闭环验证的可复现版本。后续跨场景实验应：

1. 保留 `adaptive_goal_line_045` 作为对照，不直接修改冻结文件；
2. 新建世界副本和实验分支，一次只改变一个环境因素；
3. 每个新场景独立重启三次，保存同样的图、CSV、metrics、参数和 contacts；
4. 只有三次都通过且无非地面接触，才把新场景写入验证结论；
5. 真实 D435i 接入前先验证固定安装 TF、RGB-D 帧率、深度遮挡和 `/cmd_vel_safe`，仿真数据库与真实数据库分开。

当前可复现参数的唯一详细来源是 [自适应目标线算法复现手册_2026-08-22.md](../05_自适应目标线_2026-08-21至22/自适应目标线算法复现手册_2026-08-22.md)；阶段结果入口是 [EXPERIMENT_ARCHIVE_INDEX.md](../00_项目总览/EXPERIMENT_ARCHIVE_INDEX.md)。
