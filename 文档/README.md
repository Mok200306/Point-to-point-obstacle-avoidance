- 想启动当前仿真：先看根目录 `README.md`，再看 `05_自适应目标线_2026-08-21至22/自适应目标线算法复现手册_2026-08-22.md`。

- 想回顾算法为什么改变：按 `02` -> `03` -> `04` -> `05` -> `06` 阅读。
- 想改世界或准备真实设备：看 `07_跨场景与真实设备`。
- 当前要准备静态实车或重新设计动态场景03：看 `10_实车接入与动态场景重规划_2026-08-31`。
